# Versioned Execute031 cohort

This is a small explicit successor to frozen028's Execute loop, not a whole-Execute reconstruction. `execute_core.c` retains the measured entry/dispatch structure and selects small collection/number helpers; frozen028 storage, StartCall, Return, call dispatch and integer arithmetic remain unchanged. `call_adapter.c` supplies022's Execute service. Select031's core/adapter instead of028's two corresponding translation units. The fixture selects the new entry by a compile-time identifier binding in the readonly028 fixture unit; no product, original instruction, object or relocation is patched.

The baseline is all108 frozen028 programs. The successor must reproduce their entire structured observations and fully defined source arenas, including callback code pointers kept at their prior source link addresses. Reference mode still executes original Call/Execute/StartCall/Return/NativeCall/builtin bodies with original vtables. Source mode maps compiled source only. The new programs exercise actual nested script frames, real table/array construction and mutation, byte-string and integer keys, direct lookup, PREPCALL/PREPCALLK and real native methods, typed reference returns, comparisons, bitwise/unary operations and finite floating arithmetic.

The VM/storage ABI is exact028/022; prototypes/closures/arrays/tables/strings use the named011/012/013/014/015/017/019 types. Lookup into the target VM's reserved-byte temporary does not use an incompatible typed pointer: a direct-hit frozen020 service returns a newly owned typed result, then031 transfers it into that byte-copy slot before releasing its old owner. Only direct valid table/array paths and raw misses are admitted by this adapter. General fallback, delegate/metamethod/class behavior and arbitrary reentrant mutation require separate qualification. The final-owner array case checks the publication ordering through real disposal callbacks.

The scalar cohort includes wrapping integer arithmetic and relational comparison's measured signed interpretation of wrapping left-minus-right. That comparison differs from mathematical ordering on overflow. Same-tag equality compares raw scalar bits or complete native pointers: positive/negative floating zero differ, and identical NaN payloads compare identical without a floating comparison. Mixed numeric equality and broad string/object comparisons are unqualified. Bitwise shift counts use their low eight bits, with explicit behavior for zero and counts at least32; no C shift overflow is used. The finite float cohort covers multiplication, addition and negation; authored floating subtraction is untested. Division/remainder, nonfinite arithmetic and universal FP-status equality remain outside the claim.

Nested children retain explicit external owners, including their prototype owners; this fixture does not claim a new child final-owner family or a VM/GC teardown. Parent, native, array, table, string and compact-prototype lifetime behavior is compared where reached. Native-call frame instruction/literals/target/root retain the frozen022/028 indeterminacy restriction: preserve raw differences, require no observer reads of those four cells, and compare all other initialized arena bytes. Script/collection cases compare complete arenas without masks.

Successful aligned, nonoverflowing, nonreentrant allocations, valid bounded bytecode and readonly disposal observers are required. Whole Execute, broad Set/Get/NewSlot helpers, generators, suspension, traps/unwind, debug callbacks, classes/instances, allocation failure, full game builds and physical Android execution are unqualified. Source/script inputs are synthetic validation data, not extra decompilation credit. Exact/function/source credit remains zero pending coordinator review.

The source selection is recorded by `toolscripts/squirrel_execute031_build.py`. All fixture files and generated case headers are validation-only; `native_fixture.c` is Windows-only. The fixture reuses frozen028 validation code with explicit identifier selections and small031 extensions rather than copying its object graph. Platform allocation/disposal and excluded services remain explicit external contracts. Raw original images, private reference reports and disassembly stay under private input/work storage.
