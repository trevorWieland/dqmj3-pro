Frozen wave007 vector, unlink and nested-array destruction are reused with zero duplicate interval credit. Generator creation, Yield, Resume, inline Kill and state transitions belong to the VM lane.

The generator first installs its vtable and unlinks an unmarked collectable. It frees plain trap storage, releases the saved CallInfo closure, destroys reverse varargs and saved stack, releases its main closure, then installs the base teardown identity and clears the current weak target. The source preserves backing-storage disposal and omits the unobservable empty loop. Neither destruction nor final release writes the generator state byte or clears retained frame/vector fields.
