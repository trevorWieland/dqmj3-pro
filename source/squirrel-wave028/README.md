# Execute028: bounded portable script execution

This lane reconstructs a useful **part** of update ARM Execute `0x0018d65c`. Its original body has 13,184 instruction bytes in eight ranges and 628 separately inventoried data bytes. No whole-function, exact-match, whole-VM, native-game or physical Android claim is made. The earlier 006/1001 snapshot is read-only historical evidence; its legacy object casts are not used here.

`execute.h` defines an exact named `SqVmCallStorage022` common first member and a separate Execute suffix. Actual prototypes are `SqPrototype011` with the measured 12-byte target prefix, script closures are `SqScriptClosure017`, and generic operations use the alias-safe 012 providers. Target reserved object/vector fields use byte copies. Native additional fields have their own named storage; a standalone small 020/022 allocation cannot be passed as a full 028 VM. Original root-object type/payload live at target56/60; the portable object starts at56 with its real native pointer at64.

Production selection is `storage.c`, `start_call.c`, `return.c`, `arithmetic.c`, `dispatch_call.c`, `execute.c` and optionally `call_adapter.c`. The last file supplies 022's Execute service and must replace other providers of that service. The selected transitive source files are enumerated by `toolscripts/squirrel_execute028_build.py`; fixture files are validation scaffolding and must not be linked as game services. Platform allocation, debug/error callbacks, unsupported-domain termination and the existing 022 class-instance service remain explicit providers. The error callback supplied by this fixture only qualifies the measured NULL-handler guard.

The qualified corpus uses ordinary mode0, non-generator scripts: LINE with no hook, literal/integer/raw-float/boolean/root/free-variable loads, moves, double loads/moves, NULL clearing, conditional/unconditional and short-circuit branches, NOT, vararg-count zero, wrapping integer `+`, `-`, RETURN and native CALL. Some authored branches have a narrower or untested domain: integer multiplication, ordinary script CALL, defaults, varargs, tail calls, debug hooks, generators, suspension, traps/unwind, arithmetic conversion/metamethods, remaining opcodes, allocation failure and arbitrary reentrant VM mutation are not closed by this packet. Unsupported paths terminate explicitly rather than return a fabricated successful result.

Inputs must be valid owned, aligned object graphs and finite in-bounds bytecode/control-flow paths, with positive preallocated call capacity, bounded nonoverflowing sizes and successful nonreentrant allocation. The fixture's NULL root is an explicit input; no root-table construction is claimed. Callback observations cover retain, publication, old-owner release, stack/frame/depth restoration, genuine compact-prototype/script/native/array destruction and allocation sizes. Literal depth and arity errors compose frozen020/025/015, with actual ASCII strings and NULL error-handler behavior. General formatting or exception-handler execution is not supplied.

Reference mode executes the original Call/Execute/StartCall/Return/CallNative and original array builtin without replacing their endpoints or vtables. Native registration uses original016's constructor. Its separately linked authored callback routes to unchanged original `0x001b33dc`. Source mode maps only compiled source sections and routes the same callback to authored022's array builtin. It never maps the original executable. Synthetic bytecode is test input, not recovered source credit or an ARM interpreter.

Script-only and entry-error cases compare every initialized arena byte. Native CALL exposes the independently measured original NativeCall local-frame indeterminacy at instruction/literals/target/root: the source initializes these fields to zero. Raw differences are retained and limited to their exact inactive frame cells, with lifetime/read witnesses. That native cohort claims semantic/ordered-owner state only and excludes raw inactive-frame, asynchronous and arbitrary debug observers. It does not claim universal byte or machine-state equivalence.

ARM requires enabled VFP, traps disabled and the measured scalar-global initializer prefix; this prefix is a precondition and receives no function credit. SP, integer callee saves, D8–D15 and mandatory FPSCR control fields are checked. Sticky exception status is recorded separately. AArch64 execution uses compiled Android-target objects and actual pointers above32 bits in a CPU model; Windows runs a real x64 executable. Neither establishes a playable game or physical device execution.

Run `tools/python/Scripts/python.exe toolscripts/squirrel_execute028.py --output work/squirrel-execute028/qualified`. Private reports retain observations, hashes, coverage, unsupported boundaries and returning wrong-source controls. `toolscripts/squirrel_execute028_replay.py` creates a new private copy and rebuilds all artifacts and tests. Originals, object payloads and raw disassembly stay private under `work/` or existing generated input storage.
