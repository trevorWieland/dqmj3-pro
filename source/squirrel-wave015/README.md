# Actual byte-string interning and lifetime

This lane measures five complete original entry behaviors: intern/Add and inline table growth at `0x0016b5f0` (484 instruction bytes, four pool bytes), Create at `0x0019ba68` (24 bytes), table Remove at `0x0024d9e0` (144 bytes), release at `0x0024d9cc` (20 unique prefix bytes followed by the shared 144-byte Remove tail), and destructor at `0x0068f564` (44 bytes, eight pool bytes). The physical union is 716 bytes; 860 logical entry bytes include the shared tail once per entry. Remove remains its single physical owner. Release and destructor are unseeded and require coordinator review. The actual constructor literal selects vtable `0x00851220`, whose destructor/release slots witness both entries. No source or exact credit is self-granted.

This measured Squirrel path stores raw 8-bit bytes. Hash loads at `0x0016b62c` and `0x0016b6e8` use a one-byte signed postincrement followed by conversion to an unsigned 16-bit value, and termination uses one byte at payload offset 28. Thus `0x80` mixes as `0xff80` and `0xff` as `0xffff`. Hash seed is the declared length; remaining length decreases by `(length>>5)|1`, while the input pointer advances only one byte per mix. The stored hash is recomputed after allocation/copy. There is no UTF-16 decoding or generic Unicode replacement here. The game's UTF-16 frontend/assets remain a separate scope.

The exact frozen 011 prefix is 12 target bytes. String fields are shared 12, bucket link 16, signed length 20, hash 24 and byte payload 28. This is not a collectable with GC links. Legal C flexible storage avoids introducing an out-of-bounds `char[1]` struct hack into the host source. A separate nominal allocation-header calculation preserves the original 32-byte header request: payload offset plus one rounded to natural structure alignment. Native prefix/payload/nominal header are 24/48/56 bytes. The target table is 12 bytes, native 16, with buckets then 32-bit slot/use counts. Pointer and scalar members have natural alignment.

Shared state is exactly the frozen named `SqPrefixState012`; no incompatible State view is overlaid. The actual table pointer lives at target offset 20 within `unknown_0000`. Access uses a byte-copy pointer adapter, never an unaligned typed-pointer cast. The portable provisioner must reserve `[20,20+sizeof(pointer))` in that opaque byte storage and write a valid native table pointer there. This is a component storage contract, not a complete portable shared-state layout. Other adjacent opaque fields have not been reconstructed, and future nonoverlap with a full shared state is not established. Integration must reconcile that layout explicitly.

Add returns an identical interned value without allocation or retain. For a new value it initializes only the measured prefix, copies the exact byte length, writes a one-byte terminator, stores length/hash, links the value and increments use count. Growth publishes doubled slot count before allocation; it publishes/zeros new buckets, migrates nodes by prepending in original traversal order, then disposes the old array. Create writes the shared owner only after Add returns, including cache hits. Allocation storage deliberately supplies a valid poisoned shared field; observers verify that this transient field is preserved until publication. It is not silently zeroed or assigned early.

Remove requires its target to be registered in the bucket selected by the stored hash. It handles head/middle/tail links, decrements use count, captures length before virtual destruction, and disposes the captured allocation size. The destructor installs base identity and invalidates the current attached weak target. Actual frozen 014 lazy weak creation and finalization compose with strings in both destruction orders. All callbacks use the exact frozen opaque `void (*)(void *)` table type; no legacy `SqRef` function-pointer reinterpretation occurs.

The registered-target predicate is checked independently in the ARM harness before each removal/lifetime case. The lookup and next-link traversal contain no callbacks or target-register mutation before the found branch; a finite stable chain containing the target cannot take the absent-target route. The eight bytes at `0x0024da68..0x0024da70` are unexecuted under this precondition. Their call to `0x00146590` escapes into an unqualified dependency whose entry is a NOP. Original abort/return behavior is not established. The fixture's nonreturning unsupported-path provider is never exercised and does not claim to reconstruct that dependency. Missing registration, cycles/races, malformed lengths/storage and allocation failure remain outside the admitted domain.

Source byte operations are ordinary C. Original comparisons execute the actual strlen at `0x002febd8`, Thumb comparison at `0x001010c8`, copy at `0x00301a9c` with its aligned helper `0x0017821c`, and clear at `0x00301f50`. Their complete original ranges/pools are recorded, with zero new interval credit. Graph interfaces consume strlen length, comparison zero/nonzero and byte effects; copy/clear return values are unused by these callers. Broader libc ABI behavior is not claimed. Allocation/disposal are explicit typed C providers with aligned, nonoverlapping retained storage; no game allocator recovery or physical-free claim is made.

All platforms compare typed byte buffers, complete node/weak fields, bucket/link state and ordered providers. The AArch64 model runs above 4 GiB and checks x18, saved integer/floating-point registers and stack.
