This lane reconstructs four complete ARM bodies in the measured update main image: final release `0x00665bd4` (40 instruction bytes), destructor `0x00665c60` (96 bytes and 12 pool bytes), object-vector destruction `0x0077f3f8` (128 bytes), and collectable-list unlink `0x0024d73c` (48 bytes). The actual array vtable points to the previously unseeded destructor; the measurement packet records the terminal return, following literal pool, next seeded entry and absence of overlap. The coordinator must review that census addition. The packet requests zero exact bytes and does not admit its own 312-byte behavior claim.

The source is ordinary typed C using frozen wave002 views. Target arrays are 36 bytes with 8-byte objects; native arrays are 64 bytes with 16-byte objects and naturally aligned pointers. No packed-member pointers, function-pointer signature casts, register-state translations or original executable/data blobs are used. A typed void adapter exposes the destructor through the frozen virtual-table declaration while its direct entry preserves the measured returning-this ABI.

The final-owner wrapper calls virtual slot zero and then the explicit deallocation service. The destructor installs the array identity, unlinks unmarked collectables, destroys vector elements and storage, installs the base-prefix teardown identity, then clears the current weak target. The vector deliberately reloads size, values and capacity across callbacks; reference counts retain unsigned 32-bit behavior, including the measured underflow and marked-count cases. Neither vector destruction nor logical deallocation erases retained storage. The base teardown vtable is an owned opaque identity; no later calls through its null slots are admitted.

The admitted domain is valid typed arrays and vectors, bounded allocated storage, coherent collectable-list links and normally returning callbacks. Callbacks may change the measured size, backing-storage, capacity and weak-target fields while retaining valid active control storage. Reentrant invalidation, malformed pointers, data races, arbitrary cycles, garbage collection and weak-reference methods are outside this component. The high-bit branch preserves collector ownership of unlinking. This packet does not reconstruct the original allocator: its explicit C service records logical frees over foreign memory retained for inspection. A real integration must supply compatible allocation ownership and eventual disposal.
