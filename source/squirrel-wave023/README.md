## Finite binary32 formatting

`float_text.c` is an authored numeric service, not recovered SDK source. It implements the specific `%.14g` text consumed after exact binary32-to-binary64 promotion. A finite value is an integer significand multiplied by a power of two. Negative powers are converted into an exact integer coefficient multiplied by powers of five, with a decimal scale. At most 112 decimal coefficient digits are needed; the bounded array holds 128. The service rounds the exact coefficient to 14 significant digits with ties to even, removes trailing zeros and chooses fixed/scientific style at the `-4` and `14` exponent thresholds. Signed zero is retained. There is no logarithm approximation, lookup table copied from the game or cached original output.

The admitted environment uses the C locale and nearest-even rounding. Other locales, nonfinite inputs, arbitrary binary64 inputs and general printf formats remain unsupported. Python formatting and the actual Windows UCRT provide independent text references; the UCRT receives its own explicit C-locale object and standard rounding options. All residual strings are preserved without exponent, zero, sign or whitespace normalization. The Windows runtime is used only as a reference; it is not linked into the authored ARM or Android component.

The format contract and host option meanings are documented by [Microsoft](https://learn.microsoft.com/en-us/cpp/c-runtime-library/format-specification-syntax-printf-and-wprintf-functions) and the primary [mingw-w64 header](https://github.com/mingw-w64/mingw-w64/blob/master/mingw-w64-headers/crt/corecrt_stdio_config.h). No third-party conversion implementation is imported.
