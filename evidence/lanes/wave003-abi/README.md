# Wave 003 return ABI qualification

The current proposal contains **58 exact functions and 696 instruction bytes** with an explicit typed record-pointer return. It supersedes the proposed void interface for these entries without adding coverage. The old void source and its receipt remain unchanged. The three unresolved indirect-call entries remain excluded.

The native setters load `handle->record` into the return register, assign a field through that pointer, and return with the loaded record pointer still present. This is the record pointer, not the original handle pointer. A void C declaration does not promise that observable return value to future portable callers. The new ordinary C source explicitly saves the typed record pointer, performs the assignment, and returns the saved pointer. It is under `src/native/wave003/abi-qualified/`; builds must select that current source explicitly rather than also compiling the historical void definitions.

`audit.json` reviews all 58 qualified entries and their catalogue caller relationships. It independently found 137 direct call sites and explored a bounded, overapproximating control-flow graph after each call. Outcomes included 136 overwrites before a read, five possible argument-forwarding paths into another call and five paths propagating the value to the enclosing caller's return. No explicit register read was found before overwrite in the explored contexts. Eleven Ghidra caller relationships had no independently located direct site. These results do not prove an original void interface: conditional path feasibility, indirect bindings and forwarded prototypes remain unresolved. The explicit record-pointer return conservatively preserves the native observable value.

`packet.json` is the new closed native packet. Every complete Clang object symbol and genuine LLD placement at the original virtual address matches the original bytes. Its 61 fixtures per function compare original and source-linked return pointers, full handle/record/stack memory snapshots, exact read/write footprints, preserved callee registers, SP/LR, sentinel return and instruction boundaries. This gives 3,538 original-reference fixture cases in the allocated, disjoint-object domain.

Each function also receives three independently compiled wrong-source controls: wrong stored value, wrong field layout and returning the handle instead of the loaded record. All 174 controls returned to the sentinel before producing the required typed memory or return-pointer mismatch. The wrong-return checks first establish that all memory effects were correct. Two further controls require precise unmapped-write and write-protection faults, giving 176 successful negative controls. Arbitrary exceptions cannot satisfy these controls.

`byte-alias.json` is a separate raw-memory diagnostic. Across 26 byte setters and 104 fixtures, the field write overlaps and modifies the handle's stored pointer bytes; the original and explicit-temporary compiled code retain the original loaded pointer as their return. This is not a universal or abstract-C alias legality claim. An attempted reload-after-store comparison source compiled to the same saved-pointer bodies under the selected Clang settings and therefore did not distinguish behavior. That failed sensitivity assumption and its log are retained. It is not counted among the baseline negative controls.

The current producer is `toolscripts/native_wave003_abi.py`; its immutable helper dependency is pinned in the packet. The packet also pins current source/header, historical void source/receipt, compiler, linker, native runtime, object/ELF artifacts and reproduction argv. `boundary.json` selects the same 58 previously qualified native ranges and direct-call witnesses. The caller audit and alias diagnostics add no source credit.

Coordinator clean replay, integration and acceptance remain separate. The matching public Clang profile does not identify the historical compiler. Windows/Android pointer-layout adapters and platform tests remain independent of native byte and ABI qualification; complete game execution is not established by this packet.
