# Formal-equivalence pilot, 2026-11-06

This is a research result with zero recovered-source credit and no admission-policy change. The existing normal source `src/native/wave001/leaves.c` is unchanged. Its range predicate at ARM VA `0x0069180c` still compiles to different whole-function bytes. The proposal is to compare independently modeled behavior over a complete, explicitly stated domain instead of requiring a historical compiler for this one function.

The canonical update module, complete 20-byte original span, existing Ghidra boundary descriptor and freshly decoded direct ARM caller are hash-bound in `packet.json`. The source and genuinely compiled object and source-linked ELF are also pinned. The linker places the function at its original VA; there are no unresolved dependencies, body relocations, literal pools, sibling bytes or remaining linked-ELF relocations. Other translation-unit functions and unwind metadata are outside the theorem.

## What was established

Five exported SMT queries returned UNSAT: original instructions versus the typed C expression; compiled instructions versus that expression; compiled wrong source versus its own expression; the normal C expression versus the manually stated inclusive range; and original versus linked observable contract. The formula asks whether any counterexample exists. This covers all 2^32 argument bit patterns and symbolic initial core registers/NZCV under the declared model, rather than enumerating fixtures. Both valid ARM and Thumb caller-return domains have SAT witnesses; the domain contains no argument or NZCV restriction. Z3 bit vectors distinguish unsigned comparisons from signed comparisons and represent the machine subtraction modulo 2^32. [Z3 bit-vector guide](https://microsoft.github.io/z3guide/docs/theories/Bitvectors/)

The genuine wrong source changes the upper bound to 11. Its compiled artifact produces a SAT counterexample at input 11. Original execution returns 0 and wrong-source execution returns 1 after reaching the actual return sentinel, for all 16 initial NZCV patterns and both return modes: 32 reproductions. There are also 288 original/normal-source fixture pairs. The nine-test suite independently checks model flags against concrete CPU observations on 73 inputs per body, replays the exported queries without translating the model again, rejects compiled memory access and nontermination, rejects potentially undefined C expression families, and tests the observable checker for frame/memory/return failures.

## C language and domain

The normal source is `u32 fn_0069180c(u32 x) { return x >= 1u && x <= 10u; }`, with `u32` defined as `unsigned int`. Target macros and a separately compiled C11 static-assert translation unit establish 8-bit bytes, 32-bit unsigned-int storage and maximum value 4294967295. A whitelist walks the actual typed Clang AST: one initialized unsigned parameter, unsigned integer literals and comparisons, pure logical AND, and conversion of the resulting int 0/1 to unsigned. These operations are defined for every representable argument; there is no signed arithmetic overflow, invalid shift, division, pointer validity, uninitialized input or sequencing condition to restrict that domain. Both short-circuit operands are pure and individually total. The restricted translator rejects other language operations rather than assigning them a convenient total meaning. These rules follow WG14 N1570 sections 6.3.1.3, 6.3.1.8, 6.5.8, 6.5.13 and 6.8.6.4. [WG14 C11 draft](https://www.open-std.org/jtc1/sc22/wg14/www/docs/n1570.pdf), [readable copy of the committee document](https://nepsweb.co.uk/langstand/isoC/WG14/n1570.pdf)

The machine contract starts in user-mode ARM state with Jazelle/IT state clear and an 8-byte-aligned SP. LR designates a valid mapped executable caller continuation outside the owned body: word-aligned ARM or halfword-aligned Thumb. Actual final BX LR must occur, return PC must equal LR with bit zero removed, and the returned mode must match that bit. R0 is the scalar result. R4-R11, including platform R9, SP, LR, data memory and CPSR bits other than NZCV/T are preserved. There are no data reads or writes. R1-R3, R12 and final NZCV are permitted scratch observations. A separate intentionally overstrict final-flags query finds input 10 where the two correct bodies leave different flags; concrete execution reproduces that difference. [AAPCS32](https://github.com/ARM-software/abi-aa/blob/main/aapcs32/aapcs32.rst), [Arm interworking instructions](https://support.arm.com/documentation/dui0588/a/arm-and-thumb-instructions/branch-and-control-instructions/b--bl--bx--blx--and-bxj)

## Trusted base and limits

The ISA translator consumes actual Capstone typed operands. It supports only complete contiguous A32 SUB, CMP, non-flag-setting MOV and final unconditional BX LR, with the measured condition-code subset. It computes N/Z/C/V and conditional writes, tracks all core registers, a symbolic byte-array memory, opaque preserved CPSR bits, PC and instruction-set mode, and requires actual return. PC operands, memory operands, shifts, other instructions, early returns, loops and trailing bytes fail closed. Its instruction rules were checked against Arm's compare, condition-code and interworking descriptions. [Arm CMP/CMN](https://support.arm.com/documentation/dui0801/g/A32-and-T32-Instructions/CMP-and-CMN), [Arm conditions](https://support.arm.com/documentation/dui0801/h/Condition-Codes/Condition-code-suffixes-and-related-flags)

This is a theorem about the authored restricted semantics, not a verified full-ISA or full-C implementation. Clang's AST parser, the handwritten AST and ISA translators, Capstone, Z3, Python, the host and files remain trusted. There is no independently checked proof certificate. Interrupts, exceptions, MMU/cache/timing behavior, concurrent modification and full-game execution are outside the theorem. Unicorn corroborates concrete observations and counterexamples; it does not establish the universal claim. Source-expression UB analysis is separate from binary equivalence, and the Clang AST frontend is explicitly trusted. [Clang AST documentation](https://clang.llvm.org/docs/IntroductionToTheClangAST.html)

The effective compiler is the installed public Android Clang 21.0.0, based on Android r574158c and LLVM commit `9f872551d3c681d06fd303b36f16ed5c274735eb`. This identifies the reconstruction compiler only. Z3's public wheel is 5.3.3.0, core-reported commit `430d19e697e2ec9bad79ff210d41b4a7a5fcfa3e`. `runtime.json` pins its wheel, DLL and all eleven installed Python source files and verifies those effective files against the pinned wheel. PyPI's release-wide provenance notice is retained in the research record; the selected Windows wheel's fetched publisher metadata names `Z3Prover/z3`, `release.yml`, environment `pypi`. This pilot fetched that attestation but did not independently verify its signature. [Z3 public source](https://github.com/Z3Prover/z3), [pinned public release](https://pypi.org/project/z3-solver/5.3.3.0/)

## Reproduction

Run `tools/python/Scripts/python.exe toolscripts/formal_equivalence_wave001.py` or `tools/python/Scripts/python.exe -m unittest discover -s tests -p test_formal_equivalence_wave001.py -v` from this checkout. The producer also works when invoked by absolute path from another directory. Raw disassembly, ELF objects, generated ASTs, SMT-LIB queries, solver results and execution receipts remain private under `work/formal-equivalence-wave001/`.

The project-local solver wheel and fetched publisher metadata are staged under `tools/formal-wave001/`; no shared tool lock was edited. A fresh dependency setup can download `z3_solver-5.3.3.0-py3-none-win_amd64.whl` from the public pinned release, verify SHA256 `d189844a586242fe3d2a701c09751a80d518645931931a7c6bf29df679044215`, and install it into this project's existing Python environment with `-m pip install --no-index --no-deps <wheel>`. Preserve or refetch the public PyPI wheel-provenance JSON for the runtime receipt. Missing prerequisites fail rather than skip a proof.

Before considering any general policy, independently review both translators and reproduce these query and counterexample artifacts. A later experiment could qualify another pure scalar family, add an independently checked solver/ISA semantics path and explicitly review caller contracts. This pilot does not authorize that policy change or promote any nonmatching function.
