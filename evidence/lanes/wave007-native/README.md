# Native wave 007: field predicates and bit extraction

This lane proposes **50 exact functions and 852 instruction bytes**: 45 nonzero-field predicates, three raw-mask accessors and two high-bit extractors. They read typed unsigned fields through either a direct record view or one handle-to-record pointer. No writes, calls, literal pools or body relocations occur in these admitted candidates.

The exclusive discovery claim contains 137 complete, directly referenced Ghidra functions and 2,656 bytes. Their reviewed scalar models were projected into ordinary C field comparisons, logical relations, selections and value-level bit extraction. The materialized source has no register machine, program-counter dispatch, assembly, executable blob or output patching. Partial views name unknown prefixes and measured field widths/offsets; they do not claim original class names or gameplay meaning.

All 137 models were compiled with the public Clang MPCore ARM profile at `-O2`, `-O1`, `-Os` and `-Oz`. The same 50 functions matched under all four profiles. The remaining **87 are unvalidated, nonmatching drafts with zero source credit**. Their profile failures, symbol sizes and hashes remain in `packet.json`, with objects and logs under `work/wave007-native/`. A matching translation unit does not promote its other functions.

Each proposed function has a complete exact object symbol and a genuinely linked LLD placement at its original address. The packet pins source/header, compiler/linker, object/ELF artifacts, original span, profile and reproduction arguments. The historical compiler remains unidentified. Source and header are under `src/native/wave007/`; source compilation does not invoke the model-authoring helper.

The 50-function subset passed **15,084 original/reference fixture cases**. Byte fields use all 256 values; wider fields use zero, extrema, one-hot and complementary bit patterns, predicate boundaries and seeded values. Object bases, unrelated memory, caller registers and initial condition flags vary. Both ARM and Thumb return states are tested. A separate Python scalar model predicts the result; full stack/handle/record snapshots, declared pointer/field reads, absence of writes, callee registers, SP/LR, return state and the complete instruction span are checked.

The harness steps actual owned ARM instructions and samples their condition predicates from the current CPSR. Every owned instruction is covered. All 45 predicated Boolean-result instructions are observed with both true and false conditions. This is bounded instruction/condition evidence, not proof of all execution contexts or MMIO behavior.

Each function also has a compiled wrong predicate and a compiled wrong typed-field layout. A field-specific witness distinguishes the intended field from adjacent zero-filled data. All **100 negative controls** returned to the sentinel, left memory snapshots unchanged, and then raised the specific `ReturnMismatch` exception with actual/expected scalar values. An unrelated exception cannot satisfy these controls.

`boundary.json` records complete Ghidra ranges and independently decoded direct call witnesses. Neighboring code and call context are retained privately in `work/wave007-native/contexts.txt`. `runtime.json` supplies effective package/native-library identities in addition to the packet's compiler/runtime pins. `review-summary.json` separates proposed bytes, failed-profile drafts and coordinator acceptance.

Reproduce using the repository's `tools/python/Scripts/python.exe` with the absolute `toolscripts/native_wave007.py` path from any working directory. The producer checks the frozen original and catalogue, recompiles all profiles, validates the exact subset and recreates its source-linked and negative artifacts. Independent committed-tree replay, whole-module integration and source acceptance remain coordinator decisions. No complete native game or platform execution is established here.
