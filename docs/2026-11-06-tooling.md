# DQMJ3 Professional tooling

The installed tool set is local to tools/ and pinned in tools.lock.json. Five PyPI wheels were downloaded, checked against their PyPI release SHA-256 values, and installed from the local wheel cache. CTRTool's archive matches its upstream GitHub release digest. objdiff is copied from the previously verified local distribution with the same upstream digest. Minimal Clang/LLD and their two DLL dependencies were copied read-only from the existing Android NDK r30 installation and pinned by file hash.

| Tool | Role | Qualification |
|---|---|---|
| Python 3.13.5 | Entry points and reports | Version and executable hash pinned |
| 7-Zip 19.00 | Owner archive extraction | Existing system install; successful CRC-checked extraction, no global change |
| CTRTool 1.3.0 | Independent CIA/ExeFS extraction | Upstream digest; both code and ExHeader outputs agree with pyctr-based intake |
| pyctr 0.7.6 | TMD, ExeFS and streaming RomFS readers | Pinned wheel; no boot ROM or external keys needed for these unencrypted contents |
| Capstone 5.0.9 | Native instruction analysis | Metadata, API version and actual DLL identity recorded separately |
| Unicorn 2.1.4 | Bounded ARM function oracles | Native DLL pin, actual-return and negative-control tests |
| pyelftools 0.33 | Compiler ELF inspection | Pinned wheel; linked sections/symbols parsed by validation harness |
| Clang and LLD 21 | Genuinely compiled ARMv6K behavior candidates | Minimal distribution and dependencies pinned; the infrastructure/behaviour compiler, not the identified original |
| ARM Compiler 4.1 build 1454 (armcc) | Default measurement compiler: best-evidenced original | Proprietary; not committed. Pinned public archive URL, size, SHA256 and member digests in `tools.lock.json`; `toolscripts/armcc_bootstrap.py` verifies it. See `docs/2026-11-10-armcc-compiler-profile.md`. |
| objdiff 3.8.3 | Future object/relocation comparison | Own local executable and upstream digest; not yet a complete 3DS matching pipeline |

The minimal compiler distribution deliberately has no SDK, headers or target runtime. Current freestanding no-header probes work. A broader source build must declare additional headers, libraries and linker inputs before claiming reproducibility.

## Commands

```powershell
& .\tools\python\Scripts\python.exe setup_tools.py --verify
& .\tools\python\Scripts\python.exe toolscripts\inventory.py
& .\tools\python\Scripts\python.exe toolscripts\verify_intake.py
& .\tools\python\Scripts\python.exe toolscripts\asset_survey.py
& .\tools\python\Scripts\python.exe toolscripts\native_survey.py
& .\tools\python\Scripts\python.exe -m unittest discover -s tests -v
```

Scripts resolve the repository from their own filenames and support an unrelated current working directory. `run_checks.py` is the aggregate entry point. The input archive and extracted originals remain untouched by checks. Fresh installation uses the lock's public download URLs; the private Clang copy can be supplied with `--clang-source`. Failed or missing pins cause verification failure.

`toolscripts/lock_tools.py` is a deliberate lock-authoring utility, not part of routine validation. Never refresh pins merely to clear a mismatch. Review changed upstream identities and preserve the failed receipt first.

## Candidate tools

Ghidra/CTR loaders, 3dsd, original ARM compiler versions, native Squirrel tooling, Azahar and GPU asset editors remain candidates. The architecture and validation research reports record primary URLs, observed commits and limitations. Do not download proprietary Nintendo SDKs, compiler bundles or keys from community links. An independently acquired lawful compiler must still be identified against this actual binary.

The [Project CTR tools](https://github.com/3DSGuy/Project_CTR), [pyctr](https://github.com/ihaveamac/pyctr), [Capstone](https://github.com/capstone-engine/capstone), [Unicorn](https://github.com/unicorn-engine/unicorn) and [objdiff](https://github.com/encounter/objdiff) are the primary upstream references. Public hosted decompilation services are discovery references only; this private project uploads no game content.
