# Cold mounted-archive owner session

Wave027 connects the frozen game-facing filter owner to a new typed archive adapter. It executes slot construction, the actual game factory, a filter query, and destruction as one cold session. The reference route executes measured original ARM game, filter, filesystem and SDK code against a genuine C archive provider. The authored route links prior recovered C with `src/native/wave027/owner_archive*`; it maps no original executable image or SDK helper. Immutable Unicode arrays remain an explicit data service.

This is a bounded component/API integration proof. It grants no additional recovered SDK functions, source bytes, exact matches or game-wide execution. The adapter implements the generated root-directory RomFS corpus with one directory-hash bucket, one file-hash bucket and one live file. General directories, multiple buckets, concurrent sessions, actual OS mounts and arbitrary malformed archives are outside this packet.

The archive contains seventeen named files (`0.txt` through `16.txt`) unless a case changes that set. Header, directory, metadata, UTF16 names and payload come from the generated byte array. Selection comes from the game/locale graph. Changing the archive changes delivered bytes; neither execution receives a canned match result. Complete ordered primitive and logical traces are compared. The measured SDK missing-file directory fallback has two extra private reads; only that exact suffix may differ, while status, common reads and ownership events still agree.

The SDK cache and source context have different representations. Original writes are confined to qualified four-byte stores within its measured 56-byte cache requirement. Source requires zero cache bytes and preserves the full 2048-byte caller work buffer. Its separate context has independently checked callbacks, file offset/length/live state, stream position/cache and header. No SDK pointer words are copied. Game owner/storage, caller buffers and every other compared byte remain observed; no whole-memory equivalence is claimed.

The 52-byte target owner and 65536-byte storage become a measured 96-byte native owner and 107520-byte typed storage. Target/native page requests are 65536/110592 bytes. Arena capacity remains 2624 logical slots; physical blocks widen from 16 to 32 bytes. Raw file payload lengths remain byte counts. Pointers are never truncated into integer payloads or hidden padding.

Windows runs the actual compiled DLL. The portable query helper receives an independently known caller-owned arena, reused across rules. Windows compares persistent fields and graph; it does not claim an instruction-level constructor count or expired-stack identity proof. ARM/AArch64 independently observe constructor entries and retired reads. Complete-field private lifetime exclusions keep the frozen graph contracts; partial historical pointer fragments remain unsupported.

AArch64 runs a static CPU model with source, fixture and data pointers above 4 GiB. ABI constants come from separately compiled AArch64 objects. Only four-byte `$x` ranges may execute. X18 through X29, low D8 through D15, SP and floating controls are checked. Write observers read completed memory, including 128-bit stores. This does not claim Android OS/device execution; a separate PIC DSO build is recorded.

Archive errors are measured against original execution. Null owner allocation lies outside the original factory's valid domain: it forwards null into initialization. Exhausted storage reaches the original failure helper with status `0xd8601837`; the cold reference then stops at an unmapped SDK dependency. SDK fatal completion is not claimed. These are retained separately from normal comparisons; Windows is not asked to execute C undefined behavior. The new adapter traps if a supplied fatal callback returns.

The producer is `toolscripts/native_wave027_owner_session.py`; public adapter regressions are `tests/test_native_wave027_owner_session.py`. Original inputs and preserved triage stay private under the owned work directory.
