Wave029 is a development candidate for the game's MD5 initialization, streaming update and finalization API. Its pre-source measurement records three existing canonical bodies totaling 860 instruction bytes. The previously qualified 2408-byte compression routine is reused without duplicate credit. The original update falls through into a copy service; those SDK copy bodies receive no new source credit.

The ordinary C context stores a 64-bit byte count as two unsigned words, four digest state words and a 64-byte buffer. Initialization preserves the old buffer. Finalization records the original bit length, appends standard padding and writes 16 output bytes; output/context overlap is exercised explicitly. The algorithm reference is RFC1321: https://www.rfc-editor.org/rfc/rfc1321 . No reference implementation source was copied.

The first development corpus passed 954 scenarios and 2412 API invocations on each of original ARM11MPCore, authored ARM, real Windows x64 and an AArch64 CPU model with addresses above 4 GiB. Every 4096-byte caller arena agreed.
