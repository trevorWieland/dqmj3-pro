# Public transport for bounded filesystem bootstrap 068

This adapter places the four authored production C/header files at `src/native/wave068-bootstrap/`. It preserves 117 exact public 066/067 input references, adds six C/header inputs and 29 unchanged qualification Python snapshots, and reuses three exact public guard/loader helpers. C translation units, quoted include files, qualification fixtures and metadata snapshots are declared separately. The larger allocation fixture is qualification-only; it changes physical backing capacity without changing target allocation budgets.

Run from the public repository root:

```text
tools/python/Scripts/python.exe -B toolscripts/bootstrap_file068_intake.py --output work/bootstrap068-review
```

The full run freshly compiles all three profiles, executes the actual original cold bootstrap, runs authored ARM/Windows/AArch64 startup and nine returning ordinary-source controls, then rebuilds and runs from a copied C/header/Python tree. `--source-only` omits original image access and uses the exact frozen independent original observation. `--smoke` is explicitly partial.

The transport restores declared logical source paths and quoted includes. Selected Python modules are compiled from hash-checked source bytes; their logical `__file__` is an anchor, while `__spec__.origin` and per-child import receipts identify the actual source snapshot. Declared logical import search roots are recorded without searching historical directories. Undeclared historical open/stat/lstat/listdir/scandir/resolve attempts remain terminal even when caught. Original constructors and image reads are blocked in every source phase. Native library loads use the exact runtime closure, approved Windows endpoints, and freshly compiled component libraries.

Frozen ready files, old build descriptions and control fingerprints are metadata only. Historical artifacts named inside them are never opened. Runtime ELF/DLL/object bytes are checked against frozen fingerprints before source execution. No original, artifact or tool tree is copied; compilers and runtimes are reused.

The bounded proposal is only `001054f8` and `0010c444`, totaling 256 original instruction bytes. Its filesystem services are compiled typed C qualification ports. Shutdown, alias, replacement, failure, warm startup and global dispatch behavior remain excluded. Task observation remains before start, after the worker's actual paused-event acquisition, or after join; this cold-bootstrap worker is never scheduled. Windows executes a parked native thread. ARM/AArch64 runs are CPU models. This transport adds no source credit, SDK filesystem recovery, host OS filesystem mount, physical Android startup or whole-game qualification.
