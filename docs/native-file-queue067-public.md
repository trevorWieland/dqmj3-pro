# Public input transport for native file queue 067

The transport preserves all frozen production, fixture and Python bytes from the 067 source packet. Existing public 066 helpers and fixtures are used by exact hash. New helpers and qualification files are namespaced under file067. The materialized source tree restores the declared logical paths and quoted includes; no legacy work directory, original artifact or tool tree is copied.

Run from the public repository root:

```text
tools/python/Scripts/python.exe -B toolscripts/queue_file067_intake.py --output work/queue067-review
```

The default run rebuilds all three compiler profiles, executes the original ARM session and the authored ARM/Windows/AArch64 sessions, runs the returning source controls, then repeats source execution from a small copied source tree. Original execution needs the separately verified owner inputs. `--source-only` skips original image access and compares source observations with the frozen small original-observation receipts. `--smoke` is an explicitly partial transport check.

The dependency-selection build.json is read only as metadata. Its selected source hashes and original artifact fingerprints are validated; none of the historical artifacts named inside it is opened. The two request066 private metadata views and the queue descriptor view are exact immutable snapshots. All other historical work access fails, including caught open/stat/lstat/listdir/scandir/resolve attempts. Source and tiny modes reject original image constructors and generated original image reads. Native-library loading permits only exact declared runtime libraries, approved Windows OS endpoints and the freshly compiled component DLLs.

Fresh selected Python modules are compiled from validated source bytes in each child. Their logical `__file__` is a root anchor only; `__spec__.origin` and the import receipt identify the actual snapshot. Resolving an exact logical anchor does not stat or read a legacy file. There is no cached bytecode fallback.

Task ready/error/payload observation remains restricted to before start, after the worker's paused-event acquisition, or after join. The transport grants no arbitrary concurrent-polling, kernel/filesystem/bootstrap, whole-game or source-credit claim. Android pthread/probe files are qualification-only. The separately frozen final Android v4 library remains 92,744 bytes, SHA-256 `5de925a5f58894d3243a3ce3dee0719c4dfe481d930a996f57d355e7ea4604f8`; AArch64 CPU-model replay is not a new Android device execution.
